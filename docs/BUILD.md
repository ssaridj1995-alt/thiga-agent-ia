# Construction et provenance

Le paquet technique contient deux layouts OCI locaux à restaurer dans `demonstrateur/vendor/` pour construire depuis le dépôt. Le Compose résout le manifeste Linux amd64 précis de chaque base via un contexte nommé, puis ajoute le code livré pour `mcp` et `webui-guard`. `init`, `bootstrap` et `mcp` utilisent la même image applicative. Les manifestes et tailles des blobs figurent dans [le relevé de provenance](../demonstrateur/vendor/provenance.json). Chaque blob a été contrôlé par SHA-256 avant sa mise en paquet. Les [recettes applicative](Dockerfile.app-base) et [garde](Dockerfile.guard-base) sont conservées pour la provenance. Leur reconstruction n’a pas été qualifiée comme moyen de reproduire les digests scellés. [Installation](../README.md#installation-pour-les-destinataires-du-paquet-de-remise) · [Contextes OCI Buildx](https://docs.docker.com/reference/cli/docker/buildx/build/#use-an-oci-layout-directory-as-build-context)

Le premier téléchargement de poids vient de la distribution Ollama. Le manifeste canonique de Qwen 3.5 9B Q4_K_M est `56671c2ab9385f9cfcb404638e32cd62d88e3501d44822208363c010179a3c90`. Le wrapper Ollama observé en M16 n’est accepté que si son empreinte correspond, que le manifeste d’origine est retrouvé par digest et que toutes les couches référencées concordent. Le seed rétablit alors atomiquement le manifeste canonique. Toute autre divergence ferme le démarrage. Le bootstrap revérifie le digest par API.

Les recettes archivées du garde utilisaient des index Debian authentifiés et des paquets verrouillés, soumis à disponibilité et échéance. Le choix OCI rend l’assemblage depuis le paquet indépendant de cette échéance. Pour mettre à jour les bases, reconstruire sous des sources authentifiées, vérifier les versions et avis de sécurité, remplacer les layouts et digests, puis rejouer le build et la qualification du garde. Les attestations locales relient les artefacts à leur build. La confiance dans les éditeurs, leurs signatures et la fraîcheur des dépendances restent des contrôles à maintenir.
